# SoMo Tư Duy V13 – Đọc văn bản/Kinh Thánh thành tiếng

## Cập nhật
- Thêm nút 🔊 Đọc văn bản trên giao diện điện thoại.
- Dán văn bản Kinh Thánh dài; nội dung gốc được giữ nguyên, không bị xóa sau khi đọc.
- Tự chia theo câu/đoạn và đọc lần lượt; giữ dấu câu để tạo nhịp nghỉ.
- Hiển thị câu/đoạn đang đọc; có Đọc từ đầu, Tạm dừng, Đọc tiếp, Dừng và chỉnh tốc độ.
- Tăng phiên bản cache Service Worker để điện thoại nhận bản mới.

## Cập nhật GitHub Pages
1. Giải nén ZIP.
2. Mở repository `huonghapro110-oss/somo-tu-duy` → Add file → Upload files.
3. Upload và ghi đè `index.html` cùng `sw.js` ở thư mục gốc.
4. Kéo xuống Commit changes.
5. Chờ GitHub Pages triển khai, sau đó đóng hẳn app trên điện thoại và mở lại trang. Nếu còn bản cũ, xóa dữ liệu/cache của riêng trang GitHub Pages hoặc mở tab ẩn danh một lần.

Chức năng đọc dùng giọng đọc tiếng Việt có sẵn của trình duyệt/thiết bị; cần bật âm lượng media.
