# Sơ đồ tư duy: bản Android (v10)

## Cài lên điện thoại
1. Upload toàn bộ file trong thư mục này lên một kho GitHub (Public), bật GitHub Pages.
2. Mở địa chỉ https của bạn bằng Chrome trên Android, bấm menu ba chấm, chọn "Cài đặt ứng dụng".
3. Cập nhật: upload đè file, mở app hai lần. Nếu vẫn thấy bản cũ, gỡ app rồi cài lại.

## Có gì mới ở v9 (mở menu ☰ ở góc sơ đồ)
- Thư viện nhiều sơ đồ: tạo, mở, đổi tên, nhân bản, xóa, đánh dấu riêng tư (cần PIN), tìm trong tất cả sơ đồ.
- Tóm tắt (ngoặc gom nhóm). Hoàn tác nay gồm cả quan hệ, viền nhóm, tóm tắt, giao diện.
- Xuất PNG, JPG, PDF có đủ quan hệ, viền nhóm, tóm tắt.
- Kanban và ma trận 2x2: kéo thẻ sang cột khác; nhãn trục; mẫu Eisenhower và SWOT.
- Kiểu sơ đồ mới: Lưu đồ (hình thoi, mũi tên, nhãn Có/Không), Cây quyết định, Cây dạng bảng, Bản đồ khái niệm.
- Lịch dạng lưới tháng. Chi tiết nút: người phụ trách, lặp lại, phụ thuộc, đính kèm file (tối đa 400 KB).
- Sticker, ảnh GIF động, 64 chủ đề màu và giao diện tùy chỉnh.
- Ôn tập: Đúng/Sai, Điền từ, Nối cặp, Câu hỏi mở, Tình huống, thống kê tiến bộ, mẫu "Đọc tâm".
- Nói cả đoạn rồi tự tách thành sơ đồ. Nút ＋ trên nút đang chọn: chạm hoặc kéo ra để tạo nhánh. Đổi bên nút thu phóng cho tay trái.
- Mã hóa AES-256 bằng mật khẩu (quên mật khẩu là mất dữ liệu). Xuất XMind. Nhập Word, PowerPoint, PDF (cần mạng), clipboard.
