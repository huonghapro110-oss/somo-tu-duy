# SoMo Tư Duy V15 – Thu gọn bảng điều khiển

## Thay đổi
- Thêm nút thu gọn/mở lại bảng điều khiển ở mép dưới màn hình.
- Khi thu gọn, vùng sơ đồ được mở rộng gần toàn màn hình để quan sát tổng thể.
- Thêm nút ◎ trên cụm công cụ nổi để tự căn vừa toàn bộ sơ đồ trong vùng nhìn.
- Giữ nguyên các chức năng đọc thành tiếng, ghi âm/chuyển giọng nói thành văn bản và dữ liệu sơ đồ.
- Tăng phiên bản cache Service Worker lên V15 để trình duyệt nhận bản mới.

## Cập nhật GitHub Pages
Giải nén ZIP, vào repository → Add file → Upload files, tải lên và ghi đè `index.html` cùng `sw.js`, sau đó Commit changes. Không tải ZIP lên repository.
